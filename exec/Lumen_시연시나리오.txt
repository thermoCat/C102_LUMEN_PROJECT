1. 시연 준비사항
----------------------------------------------------------------

[1] 백엔드 서버 상태 확인
    - URL: https://k14c102.p.ssafy.io/api/actuator/health
    - 응답: status: UP 확인

[2] Android 앱 설치
    - SmartCane.apk 설치 완료
    - 카카오 지도 정상 로딩 확인

[3] 스마트 케인 하드웨어 연결
    - USB 카메라를 스마트폰 USB-C 포트에 연결
    - 앱에서 카메라 인식 상태 확인

[4] Wear OS 기기 페어링
    - 스마트워치 페어링 상태 확인
    - Wearable Data Layer 연결 확인

[5] 환경 변수 / 권한 점검
    - 위치(GPS) 권한 허용 상태
    - 카메라 권한 허용 상태
    - 마이크/스피커(음성 안내) 출력 가능 상태

[6] 접근성 설정 확인
    - Android TalkBack 활성화 상태
      (설정 > 접근성 > TalkBack ON)
    - TalkBack으로 앱 내 모든 버튼/메뉴 조작 가능


----------------------------------------------------------------
2. 시연 순서 (화면별 / 실행별)
----------------------------------------------------------------

[STEP 1] 앱 실행 및 권한 허용 (TalkBack 기반 조작)
    - 전제: Android TalkBack 활성화 상태
           → 앱 내 모든 화면 요소가 TalkBack으로 읽힘
    - 화면: 스플래시 → 권한 요청 → 메인 화면
    - 동작:
        1) 홈 화면에서 앱 아이콘 한 번 탭 → TalkBack이 "Lumen, 앱" 읽기
           → 더블탭으로 실행
        2) 권한 요청 다이얼로그 → TalkBack이 권한 설명 읽기
           → "허용" 버튼 더블탭 (카메라/위치)
        3) 메인 화면 진입 → TalkBack이 첫 포커스 요소 안내

[STEP 2] 카카오 지도 로딩 확인 (TalkBack 탐색)
    - 화면: 메인 → 지도 탭
    - 동작:
        1) 화면 하단을 좌우 스와이프로 탭 메뉴 탐색
           → TalkBack: "지도 탭, 1/3"
        2) 더블탭으로 지도 탭 진입
        3) 지도 위 hazard 마커 포커스 시 TalkBack이 위치/종류 읽기
           예: "전방 50미터, 공사장 hazard"

[STEP 3] 스마트 케인 USB 카메라 연결
    - 화면: 메인 화면 상단 상태 표시줄
    - 동작:
        1) USB-C 케이블로 스마트 케인 카메라를 스마트폰에 연결
        2) USB 디바이스 권한 허용
        3) 앱 상단의 카메라 연결 아이콘이 활성화(초록불)된 것 확인

[STEP 4] 실시간 장애물 감지
    - 화면: 보행 모드 (카메라 뷰)
    - 동작:
        1) "보행 시작" 버튼 포커스 → TalkBack "보행 시작 버튼"
           → 더블탭으로 보행 모드 진입
        2) 카메라 뷰에 객체 감지 바운딩 박스가 실시간으로 그려지는지 확인
        3) 장애물 종류(사람, 자전거, 차량 등) 라벨 표시 확인
        4) 보행 모드에서는 TalkBack 안내 대신
           Lumen 자체 음성 + 워치 진동으로 즉시 피드백
           (TalkBack은 화면 조작용, Lumen은 실시간 보행 안내용)

[STEP 5] 신호등 색상 감지
    - 화면: 보행 모드 (카메라 뷰)
    - 동작:
        1) 횡단보도 신호등 앞으로 이동
        2) 신호등이 카메라 화면에 잡히면 색상(빨강/초록) 감지 결과 표시
        3) 4클래스 모델로 분류된 신호등 상태 라벨 확인

[STEP 6] 녹색 신호 음성 안내
    - 화면: 보행 모드 (음성 출력)
    - 동작:
        1) 신호가 초록으로 바뀌면 "초록 신호입니다, 건너세요" 음성 안내 출력
        2) 잔여 시간 카운트다운 안내 확인 (해당 신호등 데이터 보유 시)

[STEP 7] Wear OS 워치 진동 피드백
    - 화면: 스마트워치
    - 동작:
        1) 장애물이 감지되면 스마트워치에 진동 패턴 발생
        2) SegFormer 존(zone) 기반 진동 패턴 차이 확인
           - 좌측/중앙/우측 감지에 따른 패턴 분기
           - 거리 근접도에 따른 진동 강도 차이

[STEP 8] 위험 구역 지도 표시
    - 화면: 지도 탭
    - 동작:
        1) 지도 탭 클릭 → 주변 hazard 마커 표시 확인
        2) hazard 마커 터치 → 장애물 상세 정보 팝업(종류, 신뢰도, 신고 시각, 이미지)
        3) 새로 신고된 hazard가 실시간 반영되는지 확인

[STEP 9] 횡단보도 파이프라인 시연
    - 화면: 보행 모드
    - 동작:
        1) 횡단보도 영역 진입 시 자동으로 횡단보도 모드 활성화
        2) 카메라 + 신호등 + 위치 정보 결합 안내 출력
        3) 보행 안내 음성 + 워치 진동 동시 발생 확인

[STEP 10] 보행 세션 종료 및 기록 조회
    - 화면: 보행 모드 → 이력 탭
    - 동작:
        1) "보행 종료" 버튼 터치
        2) 세션 저장 확인 토스트 메시지
        3) 하단 "이력" 탭에서 방금 저장한 세션 조회
        4) 보행 경로, 시간, 감지된 장애물 목록 확인

[STEP 11] Swagger API 확인 (선택, 백엔드 검증용)
    - 화면: PC 브라우저
    - 동작:
        1) 브라우저에서 https://k14c102.p.ssafy.io/swagger-ui 접속
        2) API 목록 표시 확인
        3) /api/hazards, /api/traffic-lights 등 핵심 API 호출 테스트


----------------------------------------------------------------
3. 핵심 시연 포인트 요약
----------------------------------------------------------------

[POINT 1] 실시간성
    - 카메라 → 모델 추론 → 화면 표시까지 지연 최소화
    - SSE 기반 백엔드 연결로 즉시 hazard 데이터 반영

[POINT 2] 멀티 디바이스 연동
    - 스마트폰(메인 안내) + 스마트워치(진동 피드백) + USB 카메라(시야 확장)
    - Wearable Data Layer로 실시간 메시지 전송

[POINT 3] 공간 데이터 기반 안내
    - PostGIS GEOGRAPHY 컬럼으로 반경 검색
    - 신호등 표준 데이터(공공데이터포털) 활용

[POINT 4] 시각장애인 친화 UX
    - 앱 화면 조작: Android TalkBack으로 모든 UI 접근 가능
      (별도 음성 메뉴 구현 없이 OS 표준 접근성에 위임)
    - 실시간 보행 안내: Lumen 자체 음성 + 워치 진동 피드백 이중화
    - 녹색 신호 안내 음향 / SegFormer 존 기반 진동 패턴


----------------------------------------------------------------
4. 시연 환경
----------------------------------------------------------------

[디바이스]
    - Android 스마트폰 (minSdk 26, Android 8.0 이상)
    - Wear OS 스마트워치 (minSdk 30, Wear OS 3.0 이상)
    - USB-C 외장 카메라 (스마트 케인 부착)

[네트워크]
    - 모바일 데이터 또는 Wi-Fi (백엔드 API 호출)
    - GPS 신호 양호한 환경 권장

[백엔드 인프라]
    - k3s 멀티노드 클러스터 (Tailscale 기반)
    - Traefik HTTPS Ingress
    - PostgreSQL(PostGIS) + MySQL + Redis
